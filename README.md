# Denyyy

Portofolio creative frontend dari Surakarta.

Situs satu halaman: hero, proyek, keahlian, pengalaman, dan kontak. Gerak halus, tipografi editorial, dan foto yang diberi ruang.

Repo privat: https://github.com/DenyTyz/denyyy

## Menjalankan

```bash
npm install
npm run dev
```

`npm run dev` dan `npm run build` mengembalikan foto (JPG/PNG) dari `media-b64/` sebelum server jalan. Server pengembangan memakai port 8080.

## Stack

React, TypeScript, TanStack Start, Tailwind CSS, GSAP.
