# Denyyy

Portofolio creative frontend dari Surakarta.

Situs satu halaman: hero, proyek, keahlian, pengalaman, dan kontak. Gerak halus, tipografi editorial, dan foto yang diberi ruang.

## Menjalankan

```bash
npm install
npm run dev
```

Server pengembangan memakai port 8080.

## Stack

React, TypeScript, TanStack Start, Tailwind CSS, GSAP.
